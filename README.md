# goldstix.com

Static site for goldstix.com, served by GitHub Pages. Styling mirrors the
Goldstix app (`goldstix-app/src/theme/colors.js`): dark gradient, gold
#FFB300, Inter, and Salem's Goldstix sign (U+F3E8) from a symbol-only
subset of Goldstix Sans Bold.

| Path | What |
|---|---|
| `/` | Home |
| `/pay` | Browser fallback for payment links (`goldstix.com/pay?to=..&tag=..`). With the app installed, iOS/Android open the app instead. |
| `/privacy`, `/security` | Policies (DRAFT pending compliance/counsel review) |
| `/.well-known/apple-app-site-association` | Universal links for `T83S28XUNY.com.goldstix.app` |
| `/.well-known/security.txt` | Vulnerability contact |

Anything published here is a public communication of Goldstix Clearing, LLC
(a FINRA membership applicant). Get compliance sign-off before changing copy.

Fonts are SIL OFL 1.1; their licenses ship alongside in `assets/fonts/`.
